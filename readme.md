# 🌀 Spin Coating Approximation Tool

> ⚠️ **Status: Under Development**  
> Ein einfaches Python-Tool zur physikalisch-empirischen Berechnung von Schichtdicken und Spin-Geschwindigkeiten bei der Rotationsbeschichtung (Spin Coating) von Substraten.

---

## 📌 Features
- **Schichtdicken-Berechnung:** Ermittelt die Schichtdicke \( h_f \) aus Drehzahl (rpm) und Lackparametern.
- **Drehzahl-Rechner:** Ermittelt die erforderliche Drehzahl für eine Ziel-Schichtdicke.
- **Preset-Bibliothek:** Vordefinierte Werte für gängige Lacke (z. B. SU-8, AZ 1512, PMMA).
